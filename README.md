# UTS profile static page

This folder was decomposed from the uploaded Chrome `.mhtml` snapshot.

## Files

- `index.html` — main static page
- `assets/css/` — CSS extracted from the MHTML
- `assets/images/` — images extracted from the MHTML

## Use with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder, keeping `index.html` at the repository root.
3. In GitHub, go to **Settings → Pages**.
4. Set source to **Deploy from a branch**, branch `main`, folder `/root`.

## Notes

This is a static snapshot. Links to external pages may still go to the live UTS site. Embedded CSS/images from the MHTML have been extracted locally where available. The original snapshot referenced web fonts that were not embedded, so the CSS now falls back to browser/system fonts rather than requiring missing local font files.
